# Changelog

Все заметные изменения `task-understanding` фиксируются в этом файле. Проект следует [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Изменено

- Добавлены явные номера редакций, ожидаемая редакция для подтверждения и действующая согласованная версия.
- Вопросы получили постоянные Q-ID, таблицу закрытых решений и зависимости между раундами без повторных уточнений.
- Добавлено состояние `предлагается`: критерии скилла требуют отдельного принятия и не подменяют подтверждённые факты.
- Уточнены правила содержательных изменений, подтверждений, продолжения пересогласования в новом чате и повторных снимков.
- Усилена проверка полноты обязательных областей и сохранения уже известных сведений; описан переход старых живых файлов.
- Обновлены README и синтетические примеры первичного разбора и изменения согласованной задачи.
- Исходные состояния eval-сценариев заменены полными синтетическими файлами; добавлена восьмишаговая последовательность с переносом фактических артефактов.
- Добавлены проверка живых файлов, Q-ID и SHA-256 снимков, self-tests валидатора и их запуск в CI без изменения разрешений и Action pins.
- В `TESTING.md` разделены исторические результаты, новые живые прогоны, исправленные сбои и внешние ограничения проверки.

## [0.1.0] — 2026-09-04

Первый публичный релиз.

### Добавлено

- Единый русскоязычный `SKILL.md` для Codex, Cursor и Claude Code.
- Явный запуск через `$task-understanding` в Codex и `/task-understanding` в Cursor и Claude Code.
- Живой файл постановки задачи и неизменяемые снимки подтверждённых версий.
- Карта проблем по разделам после каждого нового входа: формулировка, влияние, способ разрешения и связанный вопрос заказчику.
- Разбор блокирующих и неблокирующих вопросов, допущений, противоречий и слабых решений заказчика.
- Задания на пробный материал и внешнюю проверку без автоматического запуска других Skills.
- Порог готовности к согласованию и процесс обработки новых требований после подтверждения.
- Условные reference-инструкции, чтобы редкие ветки процесса не загружались без необходимости.
- Синтетические примеры, поведенческий eval-набор, статический валидатор и CI-проверка.
- Документация по установке, обновлению, тестированию, участию в проекте и сообщению об уязвимостях.

### Ограничения

- Claude Code заявлен как beta до живого прогона.
- Плагин, OpenAI Skills API и публикация в каталогах не входят в `0.1.0`.
