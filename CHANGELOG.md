# Changelog

Все заметные изменения `task-understanding` фиксируются в этом файле. Проект следует [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-09-03

Первый публичный релиз.

### Добавлено

- Единый русскоязычный `SKILL.md` для Codex, Cursor и Claude Code.
- Явный запуск через `$task-understanding` в Codex и `/task-understanding` в Cursor и Claude Code.
- Живой файл постановки задачи и неизменяемые снимки подтверждённых версий.
- Разбор блокирующих вопросов, допущений, противоречий и слабых решений заказчика.
- Задания на пробный материал и внешнюю проверку без автоматического запуска других Skills.
- Порог готовности к согласованию и процесс обработки новых требований после подтверждения.
- Два синтетических примера, поведенческий eval-набор, статический валидатор и CI-проверка.
- Инструкции по установке, обновлению и удалению для трёх заявленных сред.

### Ограничения

- Claude Code заявлен как beta до живого прогона.
- Плагин, OpenAI Skills API и публикация в каталогах не входят в `0.1.0`.
